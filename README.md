# 保质期扫码管理

当前版本：`v3.2.0 - 手机扫码盘点版`

一个轻量 PHP + SQLite 网站，适合手机扫码录入物料批次。

本版本按 `JarvisAI-CN/expiry-management-system-clean` 最新发布版 `v3.1.0 - 安全加固版` 的模块思路重构：保留手机扫码的轻量部署方式，同时补齐发布版里的看板、分类规则、盘点单、商品库、AI 建议和导出能力。

线上已验证域名：`http://xq.80z.top/`

## 功能

- 手机扫码识别二维码内容
- 自动解析 SKU、生产日期、到期日期
- 后台维护 SKU、商品名称、分类和提前提醒天数
- 分类规则：提前提醒天数、提前下架天数、盘点频次
- 盘点单：创建盘点单、录入二维码批次、完成盘点
- CSV/TXT 文件批量导入商品
- 从 Excel 复制后粘贴导入
- 填写批次数量后保存记录
- 手机端看板汇总过期、临期、30 天内和分类数量
- MiniMax AI 根据当前库存生成处理建议
- 查看、筛选、导出录入记录

数据库表结构会在访问首页或任意页面时自动检查并升级，不需要手动运行 SQL。

## v3.2.0 更新内容

- 新增分类规则页面：维护提前提醒、提前下架和盘点频次

## 二维码格式

示例：

```text
001110742820260311#20260311#20260907
```

解析结果：

- SKU：`11107428`
- 生产日期：`2026/03/11`
- 到期日期：`2026/09/07`

## 批量导入格式

CSV 文件或直接粘贴都可以：

```text
SKU,商品名称,分类,提醒天数,下架天数
11107428,柠檬浓缩汁,果汁,7,0
12345678,其他商品,糖浆,10,0
```

也可以只保留 `SKU,商品名称` 两列；从 Excel 复制后直接粘贴到后台导入框即可。

## 本地运行

需要电脑已经安装 PHP，并启用 SQLite 扩展。

在项目目录运行：

```powershell
php -S 0.0.0.0:8000 router.php
```

电脑访问：

```text
http://localhost:8000
```

手机访问时，把 `localhost` 换成电脑在同一 Wi-Fi 下的局域网 IP。

## 摄像头说明

手机浏览器通常要求安全环境才允许网页打开摄像头。正式使用建议部署到 HTTPS 域名；如果浏览器不允许摄像头，页面仍然可以粘贴扫码结果后识别保存。
